# Souq Guide | دليل أسواق السويداء 🏙️

مرحباً بك في المستودع الرسمي لمشروع "Souq Guide". منصة رقمية ودليل تجاري يهدف إلى جمع كافة المحلات والخدمات في محافظة السويداء ضمن مكان واحد، لتسهيل الوصول إليها ومساعدة المستخدمين في إيجاد أفضل الخيارات[cite: 27].

⚠️ **حالة المشروع (Work In Progress):** يركز هذا المستودع حالياً على الواجهات الأمامية (Frontend). تم بناء التصميم بالكامل مع إثبات مفهوم (Proof of Concept) لعمليات جلب البيانات باستخدام API وهمي لاختبار محرك البحث، تمهيداً لربط الموقع بالواجهة الخلفية (Backend) لاحقاً.

## ✨ الميزات والتصميم (UI & Features)

* **واجهة رئيسية جذابة:** تصميم داكن (Dark Theme) عصري يبرز هوية المحافظة[cite: 25].
* **شريط بحث مخصص:** يتيح للمستخدمين البحث وتصفية النتائج بناءً على الكلمة المفتاحية، الفئة، والموقع[cite: 25].
* **بطاقات العرض (Cards):** استعراض المحلات والخدمات عبر بطاقات تفاعلية توضح اسم المحل، موقعه (مثل: الشارع المحوري)، تخصصه (مثل: ألبسة، أحذية)، وتقييمه[cite: 26].
* **نظام التصفح (Pagination):** أزرار تنقل سلسة بين صفحات النتائج لضمان تجربة مستخدم مريحة[cite: 26].
* **صفحة نتائج البحث:** واجهة ديناميكية تعرض النتائج بشكل قوائم طولية، مبرمجة حالياً للاتصال بـ API خارجي (Fake API) لاختبار وعرض البيانات[cite: 28].
* **معلومات التواصل:** تذييل (Footer) يحتوي على نبذة عن المنصة، مقر الإدارة، وأرقام التواصل[cite: 27].

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **إطار العمل:** Next.js لبناء واجهات المستخدم وتوجيه الصفحات.
* **البيانات (Data Fetching):** استخدام واجهة `fetch` للاتصال بـ APIs والتعامل مع العمليات غير المتزامنة.
